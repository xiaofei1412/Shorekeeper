**M01A：模型无关的最小工程基础**

负责人：本聊天模块AI（M01A唯一写入负责人）。状态：进行中（2026-11-17）。

基线：2026-11-16，总体方案v1.4、接口契约v0.4。M02A/B/C已验收，原声人工反馈已接收；主模型M00仍暂缓。开工实测Git及现有改动，不能假定本卡描述永远等于当前文件状态。

目标：给后续模块一个可复现、私有数据不会误提交的最小项目入口，并明确显示尚未接入的能力。范围限定为本地Git、隔离环境、最少schema和健康/状态API，不建设完整框架。

允许修改：.gitignore、必要.gitattributes、pyproject.toml、uv.lock、src/shorekeeper的包入口/app/config/contracts最小文件、tests/test_api.py、本任务卡；配置示例可放configs/core.example.toml。核心环境可用被忽略的.venv或local/envs/core；会话凭证、缓存和报告留local/，大文件不写C盘。

不可修改：AGENTS、README、总体方案、接口契约及旧任务卡；M02全部资产/索引/报告/脚本；用户反馈批次；游戏文件。不得上传GitHub、创建远程仓库或推送，不下载主模型/语音权重，不实现桌面UI、数据库、身份绑定、事件总线、队列、记忆、QQ和工具执行。

**工作范围。**

1. 先建立忽略规则，再初始化本地Git。至少排除local/、.env及本地凭证、虚拟环境、缓存、构建产物；不要只依赖文件后缀排除模型。明确白名单加入代码/模板/项目文档，既有tools只纳确认过的源码，不执行git add .。可使用已配置身份做首个本地提交；若身份/签名未配置，不伪造个人信息、不改全局Git配置，记录状态，工程和忽略验收仍可继续。
2. 使用隔离Python3.12与uv管理最少依赖：FastAPI、Pydantic2、Uvicorn；必要测试依赖另组。优先已有安装；确需新工具时放项目local/，不改采集宿主Python3.14或系统环境。锁定实际可复现版本，不把torch、模型和语音全部塞入核心环境。
3. 提供一个启动命令，例如uv run python -m shorekeeper；固定只监听127.0.0.1，可配置端口，冲突时报明确信息。会话令牌在启动时生成/加载到被忽略的local/runtime，日志只提示路径不打印令牌，不写入配置示例。
4. 实现契约v0.4最小切片：GET /api/v1/health、鉴权的GET /api/v1/status、鉴权的POST /api/v1/speech。health只表示进程健康；status明确inference/tts等not_configured，product_ready=false。speech只校验输入，合法请求返回503 DEPENDENCY_UNAVAILABLE，不生成假WAV或假任务成功。没有完整身份服务，不能把会话令牌描述成已实现跨平台身份绑定。
5. 只实现该切片用到的错误与SpeechRequest/Result模型。不要把全部设计字段一次造完，不写通用插件/依赖注入/工作流平台；未接能力留明确错误，不复制第二套人格或模型客户端。

**验收。**

- git status可解释；git check-ignore证明local/中的原始录音、SDK、模型/缓存、反馈和凭证路径被排除；检查索引无raw、权重、大文件或秘密。没有远程发布动作。
- 从锁文件复现安装并启动；记录Python/uv版本和命令，不只证明开发者当前环境能导入。
- 实际服务绑定loopback。health返回process_only，status需要会话令牌；无/错误令牌返回401。非法speech请求返回422，合法请求返回503与DEPENDENCY_UNAVAILABLE，不能HTTP200伪装合成成功。
- 相关接口测试覆盖鉴权、输入边界和不可用状态；不为目录/注释写镜像测试，不调用真实模型或覆盖20个角色留出题。
- 旧M02批次与报告保持不变。合法新增代码/更新本卡不能靠刷新旧snapshot掩盖；不要重跑会覆盖旧报告的采集main。
