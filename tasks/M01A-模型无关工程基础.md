在项目根执行以下PowerShell；环境变量仅影响当前shell，避免后续下载落到C盘：

```powershell
Set-Location -LiteralPath 'E:\守岸人'
$projectRoot = (Get-Location).Path
$env:UV_PYTHON_INSTALL_DIR = Join-Path $projectRoot 'local/tools/python'
$env:UV_PYTHON_BIN_DIR = Join-Path $projectRoot 'local/tools/python-bin'
$env:UV_CACHE_DIR = Join-Path $projectRoot 'local/cache/uv'
$env:TEMP = $env:UV_CACHE_DIR
$env:TMP = $env:TEMP
$uvExe = Join-Path $projectRoot 'local/tools/uv/uv.exe'
& $uvExe python install 3.12.16 --no-bin
& $uvExe sync --locked --python 3.12.16
& $uvExe run --locked python -m shorekeeper
# 可另用 --port 8766；没有 --host 参数。前台 Ctrl+C 退出。
```

uv便携包取自[官方0.13.8 Windows x64 release](https://github.com/astral-sh/uv/releases/download/0.13.8/uv-x86_64-pc-windows-msvc.zip)，保留在`local/tools/uv/`；zip SHA256为`529e78a9cec6cd7e3e014f7ecd8bda0c113969d4ed0f2efeedb85c30943325b8`，见`uv-source.json`。换工作树/机器时该被忽略目录不会由Git带过去，需先在各自local中准备同版本uv，再运行上述命令；不得把历史采集环境当核心环境。操作依据：[uv安装](https://docs.astral.sh/uv/getting-started/installation/)、[uv设置](https://docs.astral.sh/uv/reference/settings/)、[FastAPI错误处理](https://fastapi.tiangolo.com/tutorial/handling-errors/)、[Pydantic类型](https://docs.pydantic.dev/latest/api/types/)。
