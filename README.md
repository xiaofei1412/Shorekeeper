**守岸人：本地数字生命项目**

当前阶段（2026-11-22）：M04B便捷启动与关闭已验收，源代码环境准备完成后可双击项目根目录的启动入口。总体方案v1.11、接口契约v0.5。主模型验收M00继续暂缓。

用户与开发者对应守岸人认知中的漂泊者；其他用户与群成员对应漂泊者的朋友伙伴。项目目标是让同一个角色在桌面和聊天平台延续人格、记忆、语音与行动。

唯一主模型的预定目标为 **Qwen4-27B，待正式资料与本机验收**。M00以正式公开权重与本机运行条件为开工依据。Qwen4-Max云端上线和Preview活动时间不作为27B本地权重的发布日期。

项目文件的阅读顺序：

1. [协作规则](AGENTS.md)：所有模块AI开工前必读。
2. [总体方案](docs/总体方案.md)：当前决策、完整架构、素材与训练、模块分工、验收顺序。

本聊天的协调助手负责总体设计、公共接口、任务拆分和验收评估；具体实现由用户交给其他模块AI。不同聊天以这些文件恢复上下文，不假定能自动读取彼此聊天。
